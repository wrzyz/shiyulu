# 拾语录 · 句子档案馆

一座会呼吸的句子档案馆：语录不再是普通卡片，而是带图钉、微微倾斜、悬停自动摆正的“纸笺”。整站以报头式页眉、散落字条 Hero、打字机每日一句、印章分类与情绪色联动构成独特的翻阅体验。

- 22 个分类共 1036 条中英双语语录：爱情、成长、哲思、友谊、亲情、勇气、治愈、梦想、时光、生活、孤独、希望、阅读、旅行、夜晚、自然、工作、学习、古诗词、电影、歌词、禅意
- 分类即“印章”：选中某一分类后，整站主色会切换为对应情绪色（`--accent` 联动）
- 每条语录配有独立的“此句心解”解读与适用场景，语录卡与详情弹窗直接展示，分类内不再重复
- “句子盲盒”玩法：随机开出一句语录，以翻牌动画展示
- 12 篇原创小故事：相遇、成长、生活、告别四种主题，故事与语录互相连接，正文为有情绪起伏的完整短篇
- 分类浏览、全部语录、我的收藏三种视图
- 分类内搜索、全站全局搜索、热门关键词、标签与出处双重筛选
- 默认、最新、随机三种排序方式
- 无限滚动 + “拾取更多”按钮，随机拾取高亮定位
- 每日一句自动轮换、每周编辑精选、每月主题与分类数量徽标
- 语录详情弹窗：收藏、复制、分享、生成语录图片（纸张编辑卡风格）、相似语录推荐
- 已读语录统计
- 留言板与投稿墙（本地持久化）
- 夜间模式、字号调节、键盘 `/` 搜索、返回顶部
- 收藏导出与导入（JSON）
- 本地数据完整备份与恢复：收藏、已读、打卡、留言、投稿、主题与字号
- 心境推荐器：按此刻需要推荐语录，支持换一句、收藏与深入阅读
- 语录句边批注、最近阅读历史、网格/列表视图与一键清除筛选
- 每日私人手记：围绕当天语录记录心情、回看最近手记，并随完整备份迁移
- 继续上次阅读：自动找回最近打开的语录，可在当前会话暂时隐藏
- 移动端语录工具栏可折叠，减少筛选控件对阅读空间的占用
- 阅读偏好：档案内可调整字号、日夜主题与标准/舒展行距，并随完整备份迁移
- 分类默认精简展示，可按需展开全部 22 个分类
- Web Share API 分享，未支持时自动复制文字
- 网站数据统计栏（语录数、分类数、已读数、收藏数、陪伴天数）
- PWA 支持：可安装、可离线访问
- 小故事栏目：主题筛选、随机阅读、详情弹窗、关联语录收藏
- 干净封面式 Hero：手写图片只作右侧背景、左侧一主标题一按钮，底部为今日语录与页内目录条
- 语录纸笺：随机微倾角 + 图钉 + 悬停摆正拾起；故事按分类着色条并标注阅读时长
- 滚动浮现动画、顶部阅读进度条、报头中文日期与期号
- 移动端导航抽屉：完整栏目入口、打开状态锁定页面滚动、返回顶部快捷操作
- 我的拾取档案：收藏数、已读数、连续打卡、陪伴天数、分类占比与常用标签统计
- 无障碍与性能：跳过导航链接、键盘焦点样式、`/` `D` `P` 快捷键、搜索输入防抖
- 在线状态提示与离线缓存升级：页面网络优先、静态资源边缓存边更新
- 深色模式默认跟随系统，未手动设置时自动适配
- 使用参考图片作为 Hero 背景与关于区域素材

## 本地预览

在项目根目录运行任意静态服务器，例如：

```powershell
py -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 云端部署

这是纯静态网站，可直接拖拽项目文件夹到 Netlify，或推送到 GitHub 后启用 GitHub Pages。无需构建命令，发布目录为项目根目录。
